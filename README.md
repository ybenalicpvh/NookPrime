# NookPrime

A simple NookPrime Scalability Module for Distributed architecture.

NookPrime is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NookPrime.git`
2. `cd NookPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NookPrime, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
